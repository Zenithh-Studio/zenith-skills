# Character reference procedure

Agree on style before the first generation. Use one root image for identity and outfit consistency. Show the actual anchor, discuss requested changes, and record approval only after the user accepts the current image. Replacing the anchor always requires renewed approval even when generated bytes happen to be identical.

For a native Agent image tool, preserve exact job dimensions and pass the listed files as references. If the tool returns a differently sized or non-PNG image, obtain a compliant output rather than claiming import succeeded. Record the generator actually used in result.model. Derived prompts change only the required viewpoint and framing.

Inspect each real output for face, silhouette, outfit, angle, and accidental extra figures. The deterministic checker cannot establish those. Do not retry indefinitely: stop after two failed generation attempts and show the actionable error or pending job. Regeneration preserves old versions; changes to the cast design should be copied into the asset before fresh jobs are prepared.
