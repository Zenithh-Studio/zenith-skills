# Adaptation procedure

Read the whole short source or summarize every chunk with source offsets. Separate observed facts, inferred interpretation, and adaptation choices. Resolve aliases before assigning character IDs. Preserve the source's central dramatic question while reducing unnecessary locations and cast according to the brief.

A useful episode summary has a visible conflict, a consequential change, an opening hook, and an ending question. Vary escalation rather than adding repetitive revelations. Treat production budgets as editable defaults, not a reason to erase the user's intended story.

Before requesting outline approval, provide an HTML report containing concrete adaptation decisions and a workable episode breakdown. On revision, preserve surviving IDs and update every affected episode claim. Review unresolved causality, motivation, and cliffhanger payoff yourself; the validator only checks structure and source matches.
