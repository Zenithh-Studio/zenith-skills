# Character production procedure

Resolve aliases using action, relationships, and passages, not fuzzy name matching alone. Never merge relatives merely because their names overlap. For long sources, retain observations and evidence per chunk, then reconcile the roster before designing profiles.

Keep source facts separate from choices made to achieve visual distinction. Use concrete hair, silhouette, clothing, and identifying details rather than abstract adjectives. Do not put a character name into a text-only design prompt as a substitute for appearance. Keep costumes practical for repeated frames and write voice prompts without imitating a named performer.

On revision, preserve IDs and identify whether the change affects script behavior, reference images, or both. The image workflow will fingerprint design inputs; do not silently reuse old images after a design change.
