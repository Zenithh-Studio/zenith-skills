# Opening staging procedure

Read the first action of the scene before placing anyone. Later arrivals start absent. Place only objects supported by a real image when basis is image; do not confuse a prompt with evidence of what was rendered.

A top-down layout is a spatial estimate, not a copied perspective bounding box. Keep entrances, rivals, and shared objects understandable. Review intended eyelines and seated/standing behavior against the scene. For adjoining scenes in the same setting, preserve continuity unless the screenplay motivates a change.

Drag positions or use arrow keys on a character token, then adjust posture, facing, and presence with the controls. Export JSON and rerun validation. The scene's canonical opening sentence is generated from this data, so do not maintain a competing hand-written opening in storyboard data.
