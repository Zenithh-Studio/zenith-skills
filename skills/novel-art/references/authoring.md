# Art production procedure

Give every main setting a recognizable geometry, material palette, and a few visible anchor objects. Reuse parent assets for story-supported variants; keep ancestry acyclic. Different lighting must not silently change the room layout.

Inventory props for dramatic function, repeated appearance, or close-up importance. State changes such as sealed/open or clean/damaged belong to the same prop ID. Declare a concrete scale phrase and repeat it in each prompt. Keep people and hands out of clean reference plates.

Review whether each anchor can be drawn and compared. A validator can check that a prompt says "no hands"; only visual inspection can determine whether a generated image obeys it. Scenes inferred without images remain design specifications for staging.
