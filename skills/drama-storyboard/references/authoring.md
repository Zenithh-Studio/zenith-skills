# Shot planning procedure

Resolve the scene's opening first. A segment never spans locations or screenplay scenes. Make each action achievable within its cut, and allow the spoken words to fit at the agreed speaking rate. Use reaction shots and variations in distance when motivated, rather than identical cuts of uniform length.

Frame prompts describe composition, momentary pose, and lighting. Reference paths lock character, location, and prop identity. Review the actual supplied images; prompt text cannot establish their content. Keep subsequent segment openings consistent with the previous action.

Every beat must be claimed once in screenplay order. When a script changes, retain IDs for surviving beats and repair affected claims before regenerating exports. Derived timeline and dialogue files are outputs; edit canonical screenplay/storyboard data instead of patching those outputs by hand.
